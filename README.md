# 🎵 Phonothèque

Application web personnelle de gestion et d'exploration de collection musicale (Vinyles, CD, SACD, Coffrets).

## 🚀 Fonctionnalités
- **Gestion de la collection** : Ajout, modification, recherche rapide et tri personnalisé.
- **Support multi-formats** : Vinyle, CD, CD-R, SACD, Coffrets, Liste de souhaits.
- **Intégrations API** :
  - **API Discogs** : Recherche et enrichissement automatique des fiches d'albums.
  - **API Google Gemini** : Recommandations et assistant musical intelligent.
- **Base de données** : Synchronisation en temps réel avec Supabase.
- **Interface iOS** : WebApp optimisée pour écran iPhone.

## 🛠️ Technologies
- Frontend : HTML5, CSS3, JavaScript ES6
- Base de données : Supabase (PostgreSQL)
- Hébergement : GitHub Pages
